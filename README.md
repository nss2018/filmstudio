# 科普宣传片工坊

**浏览器里写乐谱、渲片子，配乐和画面同源。** 零安装、零后端、零第三方库——所有合成、渲染、编码都在浏览器里跑完，手机上打开就能用。

在线版：https://nss2018.github.io/filmstudio/

---

## 三件事

| | 干什么 | 适合谁 |
|---|---|---|
| 🎼 **音乐工厂** | 填一个主题，出一首不重复的配乐 | 不会作曲、只想拿到能用的旋律的人 |
| 🎹 **配乐台** | 图形钢琴卷帘 / cues.json 双向编辑，试听、导 wav | 想自己改的人 |
| 🎬 **宣传片生成器** | 填几段文案 → 出带配乐的视频 | 做科普短片的人 |

## 1. 音乐工厂

**填个主题（比如「群论」「量子」「热血少年」「咖啡猫」），点生成，出来一首完整的配乐。**

它不是纯随机（纯随机 = 白噪音），也不是照抄（照抄 = 侵权 + 一耳朵听出来）。做法是音乐学里最朴素那一套：**母动机 + 变形 + 曲式 + 和声约束**。

### 采集：先从素材库里拿

| 素材 | 数量 | 例子 |
|---|---|---|
| 母动机 | 12 | 固定低音型下行（帕赫贝尔型）、圣咏式级进、八度跳进（摇滚型）、大波浪、探戈切分… |
| 和声进行 | 14 | I–vi–IV–V、i–VI–III–VII、i–iv–V–i、I–IV–iii–I… |
| 鼓 pattern | 14 | 8 分网格的 kick / hat / snare 组合 |
| 风格谱面 | 7 | 科技科普 / 古典讲义 / 热血开场 / 空镜留白 / 俏皮律动 / 节奏推进 / 纪录片 |
| 音阶调式 | 7 | 大调五声、小调五声、自然大/小调、多利亚、利底亚、混合利底亚 |
| 织体 | 12 音色 | lead + bass + pad + arp 的组合，每个风格有自己的搭配 |

### 创新：再用 9 种变形算子重组

逆序 · 级数上移/下移 · 倒影 · 高八度 · 节奏拉长 · 节奏收紧 · 加经过音 · 挖气口 · 换动机尾

每个乐句抽 1–2 个算子，得到一个「乐句变体」；**变体签名会进集合查重**，同一首里不出现同样的乐句（最多试 14 次，重抽不出来才允许微重复）。

### 两条让它「不跑调」的规则

1. **强拍吸附**：整数拍上的音强制吸附到当前和弦的音（`nearest` 取最近的和弦音）。
2. **弱拍可走经过音**：弱拍有 45% 概率走向邻近的经过音，让旋律不呆板。

> ⚠️ 这里有个容易写错的地方：**别再给小调三度「减半音」**。小调音阶的级数本身已经含小三度（natural minor 的 `deg+2` = +3 半音），再减 1 就把 i 和弦的 C–E♭ 变成 C–D（大二度）——那是教科书级跑调。测试里有一条断言专门守这个。

### 怎么保证「不同、不重复」

- **同主题 + 同种子 → 逐字节相同**（mulberry32 + FNV-1a，不用 `Math.random`）
- **换种子 → 必换一首**（实测同主题 30 个种子 = 30 首不同）
- **不同主题 → 风格/调式/BPM/动机/鼓型全不同**（中文关键词库命中 + hash 兜底）
- **连点「再来一首」也不重复**：每首曲子算一个 8 位指纹（`fingerprint`），生成前先避开已出过的指纹
- 指纹还会显示在界面上，方便你记「哪首是哪首」

### 主题词是怎么判风格的

内置中文关键词表，比如：

- 群 / 对称 / 结构 / 数学 / 几何 / 证明 / 公理 / 拓扑 / 代数 → 科技科普 · 古典讲义
- 量子 / 宇宙 / AI / 算法 / 赛博 / 神经 / 基因 → 科技科普 · 纪录片
- 热血 / 励志 / 少年 / 梦想 / 挑战 → 热血开场 · 节奏推进
- 诗 / 梦 / 夜 / 海 / 月光 / 远方 → 空镜留白 · 纪录片
- 可爱 / 猫 / 咖啡 / 游戏 / 甜 → 俏皮律动 · 节奏推进

命中后 7 成概率给第一个（更专属的那个），否则在候选里挑；一个都没命中就按 hash 落表——**稳定可复现**，不会这次给你科技下次给你民谣。

生成的界面上会写清这首曲子**采了什么、怎么改的**（动机 / 和声 / 调式 / 织体 / 鼓型 + 用到的变形算子 + 指纹）。

## 2. 配乐台

### 图形钢琴卷帘

- 点空格子放一个音，**按住拖过去会连成一条**；拖音符换位置，拖它右端改时长
- **右键**或**长按**删除（手机上没右键，用长按 + 震动）
- 纵轴是五声音阶（两个八度 10 格）——**怎么点都不难听**，给非乐手用
- 右侧轨列表可改乐器 / 音量 / 加轨 / 删轨
- 图形和源码是同一份数据：图形里画的音，切到「源码」就是标准 cues.json

### cues.json 规范

```json
{
  "bpm": 84,
  "tracks": [
    { "name": "pad",   "instrument": "pad",  "notes": [{"p": "C3", "t": 0, "d": 2}] },
    { "name": "drums", "instrument": "kick", "loop": 1.0, "notes": ["x","-","x","-"] }
  ]
}
```

- `p` 音名（C4 / F#2 / Bb3），`t` 起始**秒**，`d` 时长**秒**
- 拍号写法：`{"p":"C4","beat":4}` 或 `{"p":"C4","beats":4}`（跟秒可以混用）
- `loop` 给**秒数**，整轨按这个周期反复铺（游戏 BGM 不用写满整首）
- 打击乐数组：`"x"` 敲一下、`"-"` 空一拍；字符串 `"notes": "x - x -"` 也认
- 解析错误都带位置和人话，例如 `tracks[0].notes[0] 音名 "H9" 不合法（例：C4、F#2、Bb3）`

12 种音色：`pad / organ / pluck / bass / lead / blip / bell / click / kick / snare / hat / clap`。
导出是 16-bit PCM wav，可直接剪进任何视频软件。

## 3. 宣传片生成器

填几段内容 → 选一个视觉母题 → 导出视频（**画面和配乐在同一个文件里**）。

| 母题 | 长什么样 |
|---|---|
| 概念递进 | 同心圆扩散 + 标题浮入、句子一行行展开 |
| 公式推导 | 公式逐字揭示，未揭示的是暗色，光标跟着走 |
| 数据演进 | 每段落一根柱子从零长到目标值 |
| 对比演示 | 左右分屏，中缝线随进度推进；标题写 `A vs B` 就会 split |
| 几何演化 | 多边形按段数展开旋转，顶点带辐条（对称群的画法） |

四个配色：墨蓝 / 暖橙 / 薄荷 / 纯黑白。`BPM` 和「每段拍数」决定节奏——**时长不用手填**，按段落自动排开。字幕开关在「2. 定节奏」里，字幕会按字数自动缩号，长句不会溢出画面。

### 文案助手（字幕从哪来）

- **本地模板**（默认，不联网、不要 Key）：按「主题 + 风格（科普/热血/俏皮/诗性）+ 段数」拼出片名和每段字幕，同主题每次一样，方便反复调
- **AI 通道**：填 Base / Key / 模型（DeepSeek / OpenAI / 硅基流动 / Moonshot / 自建），走 OpenAI 兼容的 `/chat/completions`。Key 只写进你自己浏览器的 localStorage，不经过本站任何服务器
- 有些服务不给浏览器跨域（CORS），直连会失败——把 `workers/proxy.js` 贴到一个 Cloudflare Worker，Base 填 worker 地址就行
- 「给个每段拍数建议」会按最长一段的字数算一个不撞帧的拍数

### 配乐从哪来

- 默认：按**片名当主题**调音乐工厂生成（同一个片名可复现，不同片名必不同）
- 「🎼 按片名现生成一首」：当场换一首新的，并把它灌回配乐台（能看能改）
- 「🎬 拿去配宣传片」：在配乐台挑好的一首直接指定给这部片子

### 导出

- **视频（含配乐）**：`canvas.captureStream` + `MediaStreamDestination` 一起录进 MediaRecorder，音画共用一套时钟，不会各走各的
- **只导配乐**：wav
- **逐帧 PNG**：每段中点一张
- **项目备份**：JSON，可以把整个片子（含自定义配乐）存下来

## 在手机上用

直接打开在线版就行。几个只在这一档才有的问题：

- **iOS Safari**：`MediaRecorder` 支持有限，老版本会自动禁用「导出视频」按钮（页面底部会显示本环境的支持情况），这种情况用「逐帧 PNG」或换 Chrome。
- **首次点击才能出声**：浏览器要求用户手势后才允许播放音频，所以第一次点「播放」如果没声音，再点一次。
- **导出文件落在下载目录**，不会自动打开。
- 分享链接加 `#film` 可以直接落到生成器：`<链接>/#film`

因为是纯前端（合成、渲染、编码全在浏览器里），所以**这就是手机测试环境**——不用装任何东西，也不联网上传任何数据。

## 本地跑

```bash
python3 -m http.server 8899
# 打开 http://localhost:8899
```

直接双击 `index.html` 也能开（脚本不是 ES module，没有 CORS 限制）。

## 测试

渲染层不依赖 DOM，可以直接在 Node 里跑（零依赖）：

```bash
node tests/node-test.js
```

50 条断言，覆盖：乐谱解析与报错、时间轴、五个母题 × 21 帧的绘制、离线合成调度，以及音乐工厂的

- 同主题同种子逐字节可复现
- 同主题 30 个种子 = 30 首不同的曲子
- 10 个主题 = 10 首不同的曲子
- 「保证不重复」连出 12 首零冲突
- **所有旋律/低音/铺底音都在当前调式内**（守那个小调三度的坑）
- **变形算子真的生效**（守 `usedOps[o.id] < 3` 那个 undefined 比较的坑）
- 工厂产物能过 `parseScore` + `renderScore` 出音频

浏览器端验收可以用 `tests/browser-probe.html`（自检页，结论写在页面上）。

```
tests/

```

## 已知限制

- 音乐工厂只判**和声与结构**，不判审美：调式内 + 强拍合规 ≠ 好听
- 素材库是内置的公有领域风格动机，**不是真的在听你给的歌**；想扩语料直接改 `js/factory.js` 里的 `MOTIFS` / `PROGS` / `PATTERNS`
- 工厂生成不联网、也没有版权问题（素材是程式化的通用语汇）；要「像某首歌」请别用
- 只判画面不判**审美**：节奏拖沓、配色难看它不管
- 字幕按段内固定行排，不做逐词断句
- 导出视频走浏览器编解码器，码率和帧率跟平台有关；长片（>2 分钟）建议分段导出再接
