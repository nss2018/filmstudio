不是纯随机（纯随机＝噪音）。它先从素材库采动机 / 和声进行 / 鼓型 / 织体，再用 9 种变形算子（逆序、移位、倒影、拉长…）重组，每个乐句都查重。同主题同种子必出同一首；换种子必换一首。

怎么读这份乐谱

{
  "bpm": 84,
  "tracks": [
    {"name":"pad",  "instrument":"pad",  "notes":[{"p":"C3","t":0,"d":1.8}]},
    {"name":"drums","instrument":"kick", "loop":1.0, "notes":["x","-","x","-"]}
  ]
}
  • p 音名（C4 / F#2 / Bb3），t 起始秒，d 时长秒
  • t 省略则按 beat/beats 写拍号
  • loop 给秒数，整轨按这个周期反复铺（BGM 用）
  • 数组里 "x" 敲一下、"-" 空一拍

接豆包 / 火山方舟：选上面的「火山方舟 豆包 Doubao」→ Base 和模型会自动填好，把 方舟控制台 → API Key 管理 里复制的 API Key 粘进 Key 框（打开页面时它会自动回填上次存的），这个 Key 已开通 / 已建好的模型会自动列在「模型」下拉里直接选，不用去控制台抄名字；换 Key 或换服务商时点一下上面那个按钮重拉。
方舟 401 就这三条，挨个看：
① 别拿错 Key。方舟有两套密钥：控制台「密钥管理」里的 AccessKey / SecretKey（AKLT 开头，要 HMAC 签名，Bearer 不认它）和「API Key 管理」里的 API Key（ep-/sk- 那串，直接 Bearer 用）。这里要后者。
② Base 必须以 /api/v3 结尾：https://ark.cn-beijing.volces.com/api/v3，不是 /v1。
③ 模型要选你账号开通过的那个。方舟按账号授权模型，模型名写错/没开通（哪怕写成 doubao-seed-2-1-pro 这种官方名字）都会 401。点「拉这个 Key 已开通的模型」，有 ep- 开头的「推理接入点」优先选它（那是你自己在控制台建过、必定有权限）。
某些服务不给浏览器跨域（CORS），直连会失败——这种情况把仓库里的 workers/proxy.js 贴到一个 Cloudflare Worker，Base 填那个 worker 地址就行。

1. 填内容

2D 母题适合讲道理，3D 适合讲生活
按文案自动分镜
分镜摘要会写在这里：每段在哪、谁出场、什么镜头、什么光。
分镜是种子驱动的：同文案 + 同种子 = 同一部片子；点「换一版」换种子，地点走位、镜头、氛围都会变，但主角和叙事线不变。AI 导演只允许「调」，地点/角色/动作/镜头都按白名单校验，模型编的非法值会被本地规则顶掉。
每一段 = 视频里的一幕：正文会作为底部字幕显示并朗读（选了配音的话），文字里的关键词决定 3D 场景与角色。改完文案 3D 分镜会自动重排。
